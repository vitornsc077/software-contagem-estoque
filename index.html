Configurações do Obsidian

Configure a integração com o plugin Local REST API do Obsidian. Os dados são salvos no seu navegador (localStorage).

Padrão seguro do plugin: https://127.0.0.1:27124 (ou http://127.0.0.1:27123 para HTTP)
Encontrada em: Obsidian > Configurações > Local REST API > API Key.
Exemplo: Contagens/ ou Estoque/2026/
⚠️ Dica importante sobre Certificado SSL / Conexão Local: Como o plugin Local REST API do Obsidian utiliza certificado SSL autoassinado em HTTPS por padrão, seu navegador pode bloquear requisições para localhost. Se o teste falhar:
  1. Abra este link em uma nova aba: Abrir URL do Obsidian no navegador
  2. Se aparecer a tela de aviso de segurança ("Sua conexão não é privada"), clique em Avançado > Continuar para 127.0.0.1 (não seguro).
  3. Pronto! O navegador lembrará da autorização e as requisições funcionarão direto.
